Design System

Calm structure, rare highlights.

Aubergine does the structural work, iris marks actions, and lemon appears only where something is due today — so when a user sees yellow, it always means the same thing.

Palette

Components

Buttons

Mark doneSnooze to tomorrow

Primary = the one finishing action on the screen. Secondary always names where the task goes — never a vague “Later”.

Task row

💧 Water — Monstera • about 2 cupsDue today

Action, plant, and amount in one line, readable one-handed.

Progress

Progress is always paired with a count in words (“7 of 10”) — the bar alone is never the only signal.

Type

Headings — Georgia, warm and editorial

Body — system sans, 1rem / 1.6, for fast scanning on a phone in bright light.

Accessibility notes

Never color alone

Health, due dates, and progress all carry a word or a count alongside any color.

Large tap targets

Tasks and primary buttons are full-row / generous-height, designed for one-handed use.

Real structure

Skip link, labelled navigation with aria-current, a real table for the screen map, and role="img" labels on progress bars.
